Yeni Sağlayıcı / Proxy Ekle

Gerçek sağlayıcıya (OpenAI, Anthropic vb.) doğrudan gidiyorsan "Upstream URL" alanına onun API kökünü yaz (örn. https://api.openai.com). Kendi kurumsal/iç ağ proxy'ne gidiyorsan oranın kökünü yaz. API key değişmez; sadece client'ının "base URL" ayarını buradan üretilen proxy adresine çevirirsin.
